# 全仓库中文代码注释设计

## 目标

为 Movie Harbor 仓库中除 `demo/` 外的代码建立统一、可持续的中文注释标准，使维护者在阅读函数和关键调用链时能够直接理解：

- 函数或类型承担什么职责；
- 函数通常在什么阶段、由什么入口或场景调用；
- 关键函数为什么在当前位置调用，以及调用结果如何影响后续流程。

本次工作只改善可读性，不改变运行行为、接口、数据结构、测试断言或部署机制。

## 覆盖范围

以下内容全部纳入：

- 后端 Rust 源码与测试；
- SeaORM 迁移；
- 前端 React、TypeScript 与 JavaScript；
- MCP 服务、工具与测试；
- 根目录工具脚本、契约测试与端到端测试；
- 生成文件和类型声明文件；
- 纯类型、接口、结构体、枚举及数据传输对象。

`demo/` 及其内部文件完全排除，不新增或修改注释。

## AGENTS.md 长期约束

在仓库根 `AGENTS.md` 的开发工作流中加入以下强制约束：

1. 新增或修改代码时必须同步维护中文注释。
2. 每个命名函数、方法、React 组件和 Hook 都要说明功能及调用时机。
3. 简单函数同样需要注释，不因实现短小而省略。
4. 关键函数调用点要说明调用原因、所处阶段和结果用途。
5. 类型、测试、迁移、生成文件与纯类型声明同样适用。
6. 注释必须与当前实现一致；行为变化时同步更新相关注释。
7. 不使用无信息量的逐语句复述代替职责和调用关系说明。

## 注释规则

### 函数与组件

每个命名函数、方法、React 组件和 Hook 的相邻位置必须有中文注释，至少回答：

- 功能：该函数完成什么工作；
- 时机：由哪个入口、生命周期、命令、路由、测试或业务阶段调用。

公开 API 可沿用语言原有的文档注释形式；内部实现优先使用普通行注释。不得仅为统一形式而把全部内部注释升级为文档 API。

### 匿名回调

极短匿名回调不要求逐个插入独立注释，避免破坏 JSX、链式表达式和局部可读性。其用途必须由外层函数注释或关键调用点注释覆盖。承担独立业务分支、异步副作用或错误处理的匿名回调需要单独说明。

### 关键函数调用

以下调用属于重点：

- 认证、授权、会话和密码处理；
- 事务、锁、并发控制和数据库写入；
- 生命周期、发布、删除及状态转换；
- 文件上传、校验、替换、恢复和物理删除；
- 网络请求、跨服务调用和外部进程；
- 构建、打包、导入、转换及部署步骤；
- 跨模块公共函数和会影响后续控制流的调用。

注释应解释为什么在当前阶段调用、失败如何处理或结果如何被后续逻辑使用，而不是简单改写函数名。

### 类型、测试、迁移与生成文件

- 类型、接口、结构体和枚举说明用途、数据边界及主要使用方。
- 测试函数说明验证目标和触发场景；测试辅助函数说明由哪些测试阶段调用。
- 迁移升级与回滚函数说明执行时机和数据结构影响。
- 生成文件与纯类型声明也添加中文说明；若文件会被重新生成覆盖，应在文件级注释中明确这一风险。

## 实施边界

- 只修改注释和 `AGENTS.md` 规则，不重构或调整业务代码。
- 不修改 `demo/`。
- 不为了便于加注释而改写函数、拆分表达式或调整格式。
- 保留必要英文技术名词、协议名、类型名与代码标识，但说明主体使用中文。
- 发现现有注释与实现不一致时，以当前实现为准修正注释，不借机改变行为。
- 仓库中原有的未提交用户文件保持不动。

## 实施方式

按模块分批处理，避免一次性审查超大差异：

1. 更新 `AGENTS.md`。
2. 后端运行代码、实体与迁移。
3. 后端测试。
4. 前端公开站、管理后台和共享包。
5. MCP 运行代码与测试。
6. 根工具、根测试、E2E、配置和类型声明。
7. 全仓库覆盖审计和最终验证。

每批只提交注释差异，并对照函数清单检查是否遗漏命名函数、组件、Hook、测试及迁移入口。

## 验证

完成后至少执行：

- 自动扫描：排除 `demo/` 后，检查命名函数、方法、组件、Hook、测试和迁移入口是否具有相邻中文注释；
- 差异审计：确认除 `AGENTS.md` 外，代码文件只有注释变化；
- `git diff --check`；
- Rust 格式、Clippy 与完整测试；
- 前端及 MCP 工作区测试和构建；
- 根 Node 契约测试；
- 涉及跨服务执行文件时运行现有 E2E 安全检查，纯注释不额外改变业务验收预期。

由于注释覆盖整个仓库，验证命令必须在最终代码树上重新运行并读取最新输出，不能沿用历史结果。

## 完成标准

- `AGENTS.md` 已固化新约束；
- `demo/` 无差异；
- 覆盖范围内每个命名函数、方法、组件和 Hook 均有功能及调用时机说明；
- 关键调用点具有原因和结果用途说明；
- 测试、迁移、生成文件和纯类型声明已覆盖；
- 注释与实现一致且以中文为主体；
- 除注释和 `AGENTS.md` 外没有代码行为变化；
- 相关格式、构建、测试和差异检查全部通过。
