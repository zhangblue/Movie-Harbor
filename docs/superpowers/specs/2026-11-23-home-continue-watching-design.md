# 首页继续观看设计

普通观影用户登录后，可在首页直接续播最近没有看完的公开或私密电影和剧集。记录在当前浏览器积累，按账号隔离。旧记录继续用于原有匿名播放器的本机续播，不导入账号记录。跨设备同步和自动下一集另行设计。片单已取消。

## 首页与播放

在目录首页顶部显示「继续观看」，按有效进度的更新时间降序排列。每部电影或剧集只有一张卡片。剧集卡片显示对应季集，指向确切单集。点击卡片后在媒体元数据就绪时定位到已保存位置，并尝试播放。浏览器阻止自动播放时，保留定位位置并允许手动播放。

实现默认值为无筛选首页最多显示六张。近片尾清理沿用现有播放器规则。没有有效记录时隐藏区块。

## 账号和访问边界

用当前会话确认的普通用户 UUID 划分本机记录。UUID 避免同名账号重建时继承旧记录。匿名和仅管理员登录时隐藏区块。会话退出、失效或切换账号时同步清除旧账号的渲染结果，并忽略迟到的详情响应。

本地记录只保存用于定位内容和续播的标识、时间与进度。标题、海报、季集信息与当前可播放性通过现有公开详情接口确认。详情请求失败或内容、单集不可播放时跳过对应记录。首页区块的失败不影响目录。播放器和媒体请求继续走现有授权链路。
