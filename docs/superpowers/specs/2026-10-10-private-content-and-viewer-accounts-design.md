# 私密内容、普通用户与严格媒体鉴权设计

## 背景与目标

Movie Harbor 当前只有管理员认证，公开站的目录、搜索、详情和媒体地址都面向匿名访客。新增需求是在不改变管理员职责的前提下，为电影和整部剧集增加“公开/私密”访问范围，并提供独立的普通用户登录能力：匿名访客继续免登录浏览公开内容，普通用户登录后可浏览全部已发布内容，管理员只负责内容和用户管理，不作为普通用户观看影片。

本设计采用“独立普通用户体系 + 统一媒体鉴权”方案。私密保护必须覆盖目录、搜索、详情、播放信息、海报和视频直链，不能只依赖前端隐藏。媒体鉴权通过 Caddy 的前置鉴权完成，授权通过后仍由 Caddy 提供静态文件和 Range 分段传输，后端不把大视频读入内存。

## 核心决策

- 管理员与普通用户使用独立的数据表、会话 Cookie、登录入口和权限校验链。
- 现有管理员账号及内容管理职责不变；管理员不能以管理员身份在公开站观看影片。
- 普通用户之间不绑定内容。任一已登录普通用户都能查看全部已发布私密内容。
- 普通用户名创建后不可修改，所有普通用户名忽略大小写保持唯一；管理员用户名不参与普通用户名唯一性判断。
- 管理员可以创建、修改密码和删除普通用户，不提供修改用户名或角色提升功能。
- 普通用户可以在公开站修改自己的密码，但必须验证当前密码。
- 电影和剧集保存独立的 `is_private`；季和单集不保存该字段，始终继承所属剧集。
- 私密属性与草稿、已发布、已归档生命周期独立。管理员可直接切换任意状态电影或剧集的访问范围，立即生效。
- 现有内容迁移后默认公开，避免部署升级后改变当前公开站展示结果。

## 权限模型

| 资源 | 匿名访客 | 普通用户 | 管理员后台 |
| --- | --- | --- | --- |
| 已发布公开电影或剧集 | 可浏览和播放 | 可浏览和播放 | 可管理和预览 |
| 已发布私密电影或剧集 | 不可发现、不可访问 | 可浏览和播放 | 可管理和预览 |
| 草稿或已归档电影、剧集 | 不可访问 | 不可访问 | 可管理和预览 |
| 已发布剧集中的已发布单集 | 按剧集访问范围 | 按剧集访问范围 | 可管理和预览 |
| 草稿或已归档单集 | 不可访问 | 不可访问 | 可管理和预览 |

匿名访问私密内容详情、播放信息或媒体文件时统一表现为不存在，不返回标题、媒体路径或“该内容为私密”等可用于枚举的信息。公开目录、搜索和详情接口不接受客户端传入“包含私密内容”参数；可见范围只能由服务端验证后的普通用户会话决定。

管理员会话只赋予后台管理和媒体预览权限，不会让公开目录自动进入“全部内容”模式。普通用户会话同样不能访问任何管理接口。

## 数据模型

### 内容访问范围

为 `movie` 和 `series` 增加：

- `is_private BOOLEAN NOT NULL DEFAULT FALSE`

数据库不在 `season` 或 `episode` 上增加私密字段。剧集海报和单集视频授权时通过“媒体资产 → 剧集”或“媒体资产 → 单集 → 季 → 剧集”取得整剧访问范围。

访问范围修改沿用内容的版本号和乐观并发控制。成功修改时增加版本号；过期版本返回并发冲突，避免覆盖管理员的其他修改。

### 普通用户

新增 `viewer_user`：

- `id UUID` 主键。
- `username`：保留管理员创建时的显示形式，创建后不可修改。
- `normalized_username`：去除首尾空格并进行大小写归一化，建立唯一索引。
- `password_hash`：使用现有认证模块同等级的密码哈希策略。
- `last_login_at`：最近一次成功登录时间，可为空。
- `version`：管理员修改密码和删除时使用的并发版本号。
- `created_at`、`updated_at`。

新增 `viewer_session`：

- `id UUID` 主键。
- `viewer_user_id` 外键，删除用户时级联删除会话。
- `token_hash` 唯一索引，只保存随机会话令牌摘要，不保存明文令牌。
- `created_at`、`expires_at`。

用户名唯一性只约束普通用户。`Summer`、`summer` 和带首尾空格的同名输入视为同一用户名；删除用户后可以重新创建该用户名。

## 普通用户认证

公开站新增独立接口：

```text
POST  /api/viewer/login
POST  /api/viewer/logout
GET   /api/viewer/session
PATCH /api/viewer/password
```

- 登录失败统一返回“用户名或密码错误”，不暴露账号是否存在。
- 登录沿用管理员认证的来源校验、速率限制、安全响应和密码哈希规则。
- 普通用户 Cookie 使用独立名称 `mh_viewer_session`，设置 `HttpOnly`、`SameSite=Lax`、配置驱动的 `Secure` 和 `Path=/`。
- 目录、搜索和详情使用可选普通用户会话：没有 Cookie 时按匿名处理；无效或过期 Cookie 不获得私密权限，前端清理登录状态并恢复公开目录。
- 普通用户修改密码时必须提交当前密码和新密码。修改成功后在同一事务中更新密码摘要并撤销该用户全部会话，当前设备也退出登录，随后必须使用新密码重新登录。

管理员与普通用户即使使用相同用户名也不会混淆，因为两者使用不同入口、表、Cookie 和验证中间件。

## 管理员用户管理

新增管理接口：

```text
GET    /api/admin/users?q=&page=&size=20
POST   /api/admin/users
PUT    /api/admin/users/{id}/password
DELETE /api/admin/users/{id}
```

用户列表固定每页 20 条，支持按用户名搜索。响应除分页项目外提供普通用户总数、当前至少拥有一个有效会话的用户数和最近创建用户，用于已确认 Demo 中的概览卡片。

- 创建用户提交用户名和初始密码；新用户无需在首次登录后强制改密。
- 用户名创建后不可修改，因此不提供普通用户资料更新接口。
- 管理员修改密码不需要旧密码，但必须提交目标用户版本号。成功后立即撤销该用户全部会话。
- 删除用户需要目标用户版本号和二次确认；删除后通过外键级联清理会话。
- 用户不存在或版本过期时返回稳定的不存在或并发冲突错误。
- 普通用户不能被提升为管理员，也不提供创建更多管理员的入口。

后台侧边栏新增“用户管理”。页面沿用已确认 Demo：概览卡片、用户名搜索、分页列表，以及“添加用户”“修改密码”“删除”操作。列表不显示或提供修改用户名入口。

## 内容管理界面

内容列表新增“访问范围”筛选和状态列：

- 状态显示“公开”或“私密”。
- 每条电影或剧集提供“设为私密”或“设为公开”，操作文案描述目标状态。
- 草稿、已发布和已归档内容都可直接切换，不要求先归档或转回草稿。
- 切换成功后立即刷新列表中的状态和版本；冲突时提示重新加载。

新建电影或剧集时提供“公开/私密”单选项，默认公开。电影编辑器在电影层级显示该选项；剧集编辑器只在整剧基本信息中显示，并明确说明所有季和单集继承整剧设置。季和单集编辑区域不出现私密选项。

## 公开站体验

公开站右上角新增普通用户登录区域：

- 未登录显示“登录”。目录和搜索只展示已发布公开内容。
- 登录成功后立即刷新当前目录，展示全部已发布内容，包括私密内容。
- 私密内容卡片和详情显示锁形标识或“私密”标签，帮助已登录用户识别访问范围。
- 登录后显示当前用户名，并提供“修改密码”和“退出登录”。
- 修改密码成功或退出登录后，立即清理私密详情状态并重新加载公开目录。
- 不提供“包含私密内容”开关；是否包含私密内容完全由普通用户登录状态决定。

普通用户名不可在公开站修改。管理员登录入口和公开站普通用户登录入口保持分离。

## 公开 API 可见性

现有目录和详情地址保持不变，查询条件在后端统一增加可见性约束：

- 匿名目录与搜索：`status = published AND is_private = false`。
- 已登录普通用户目录与搜索：`status = published`。
- 电影详情：匿名请求额外要求 `is_private = false`。
- 剧集详情：按整剧 `is_private` 判断；返回单集时仍只包含有效已发布单集。

公共 DTO 可在已登录响应中包含 `is_private`，用于展示私密标签；匿名响应永远不会包含私密对象。涉及可选身份的目录和详情响应设置禁止共享缓存的响应策略，避免代理缓存把登录用户结果提供给匿名请求。

## 严格媒体鉴权

### 请求流程

所有 `/media/*` 请求在 Caddy 读取文件前调用后端媒体授权接口。Caddy 将原始请求方法和 URI 传给授权接口：

1. 后端只接受规范化的 `/media/<storage_key>`，拒绝路径穿越、任意绝对路径和无法映射的存储键。
2. 通过现有媒体资产所有权关系查找电影海报、电影视频、剧集海报或单集视频的唯一所有者。
3. 根据内容生命周期、访问范围、普通用户会话和管理员会话计算授权结果。
4. 后端返回成功时，Caddy 继续使用静态文件服务发送文件；否则返回不泄露资源信息的拒绝响应。

Caddy 继续负责大文件、条件请求和 Range 分段播放。授权接口只查询元数据，不读取媒体文件，也不把视频载入后端内存。

### 媒体判定规则

- 电影海报和电影视频继承电影状态与 `is_private`。
- 剧集海报继承整剧状态与 `is_private`。
- 单集视频要求整剧已发布且单集自身已发布，并继承整剧 `is_private`。
- 匿名访客只允许访问已发布公开内容的媒体。
- 普通用户允许访问已发布公开或私密内容的媒体，但不能访问草稿或已归档内容及单集。
- 管理员会话允许预览所有状态的受控媒体。
- 无归属、所有权冲突、路径异常或权限不足均拒绝访问。

现有管理员 Cookie 当前只覆盖 `/api/admin`，浏览器请求 `/media/*` 时不会携带该 Cookie。为保留后台媒体预览，管理员 Cookie 调整为 `Path=/`，但仍保持独立名称、`HttpOnly`、`SameSite`、`Secure` 和服务端管理员校验。升级登录和退出流程同时清理旧 `/api/admin` 路径 Cookie，避免同名不同路径 Cookie 并存。公开 API 忽略管理员 Cookie，只有媒体授权和管理 API 读取它。

私密媒体响应不得进入共享缓存。授权结果不生成长期可转发的签名链接，也不把真实文件系统路径返回给普通用户。

## 导入、导出与兼容性

内容 JSON 在电影和剧集对象上增加 `is_private`：

- 季和单集不包含该字段。
- 旧导入文件缺少字段时按 `false` 处理。
- 新导入文件可以恢复电影和整剧的私密状态。
- 普通用户、密码摘要和会话不进入内容导出文件。

数据库迁移为现有电影和剧集写入默认公开值。API 新增字段时保持旧客户端可以忽略未知字段；导入工具显式兼容缺失字段，而不是要求用户修改旧文件。

## 事务与会话失效

- 管理员修改普通用户密码：锁定并校验目标用户版本，更新密码摘要和版本，删除该用户全部会话，在一个事务中提交。
- 普通用户修改自己的密码：校验当前密码后更新摘要和版本，删除全部会话，在一个事务中提交。
- 删除普通用户：校验版本后删除用户，依赖外键在同一事务中删除会话。
- 切换内容访问范围：更新 `is_private` 和内容版本；媒体授权的后续请求立即读取新状态，不使用延迟权限缓存。

任何事务失败都不返回部分成功。密码修改响应不返回密码摘要或会话令牌。

## 错误与安全响应

- 重名普通用户返回稳定的冲突错误；大小写变体按重名处理。
- 密码强度沿用现有管理员密码规则，前后端显示一致的本地化提示。
- 登录限速同时考虑来源地址和归一化用户名，成功登录不绕过后续暴力尝试保护。
- 未授权私密详情和媒体返回不存在语义；已登录但会话过期时前端恢复匿名状态。
- 管理接口继续使用管理员认证、来源校验和统一错误封装。
- 媒体授权不得相信客户端提交的内容 ID、所有者类型或本地路径，只从受控存储键和数据库所有权推导。

## 测试与验收

### 数据库与后端

- 迁移后现有电影和剧集均为公开；`is_private` 不可为空。
- 普通用户名忽略大小写唯一，创建后没有修改用户名接口。
- 用户创建、登录、退出、密码修改、删除及会话级联删除正确。
- 管理员或普通用户修改密码后，旧密码和全部旧会话立即失效。
- 匿名目录、分页和搜索不返回私密内容；普通用户登录后可以返回私密内容。
- 匿名猜测私密电影、剧集和播放信息地址统一得到不存在响应。
- 电影和剧集在所有生命周期状态下都可独立切换访问范围，并正确执行版本冲突保护。
- 剧集没有季或单集私密字段，所有媒体授权均继承整剧设置。
- 匿名访问私密电影海报、电影视频、剧集海报和单集视频均失败。
- 普通用户能访问已发布私密媒体，但不能访问草稿、已归档或未发布单集媒体。
- 管理员仍能预览全部状态的受控媒体。
- Caddy 授权后的电影和单集视频仍支持 Range 请求。
- 无归属、异常存储键和路径穿越请求被拒绝。
- 内容导出和新旧格式导入正确处理 `is_private`。

### 前端

- 公开站登录前后目录、搜索和私密标签正确变化。
- 登录、退出和普通用户修改密码流程正确；改密后回到未登录状态。
- 用户管理页只提供添加、修改密码和删除，不出现修改用户名。
- 管理员修改密码和删除用户都有明确影响说明，删除要求二次确认。
- 内容列表可筛选并切换公开/私密，切换后状态立即更新。
- 新建电影和剧集默认公开，也可明确选择私密。
- 剧集只在整剧基本信息中显示访问范围，季和单集编辑区域不显示该选项。

### 端到端

创建公开和私密电影、公开和私密剧集及包含草稿和已发布单集的混合数据，分别以匿名访客、普通用户和管理员身份验证目录、搜索、详情、海报、视频直链、Range 播放、后台预览、访问范围切换、用户密码修改及会话撤销。测试使用隔离 Compose 项目和数据目录，不使用生产默认数据路径。

## 非目标

- 不为普通用户分配独立片单或逐内容权限。
- 不允许普通用户修改用户名，也不实现找回密码、邮箱、注册、邀请、禁用或角色体系。
- 不允许普通用户进入管理后台，不允许管理员创建更多管理员或提升普通用户权限。
- 不对季或单集单独设置公开/私密。
- 不实现 DRM、一次性视频链接、防录屏、防下载或外部身份提供商登录。
- 不改变草稿、发布、归档和永久删除的既有生命周期规则。
