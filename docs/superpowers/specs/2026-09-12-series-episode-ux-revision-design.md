# 剧集单集体验修订设计规格

日期：2026-09-12

## 1. 背景与目标

当前单集模型、管理表单和公开接口均包含简介字段，但实际维护单集时不需要单独填写简介。剧集详情页又以一集一行的方式展示，信息密度偏低；播放页的上一集和下一集按钮只显示方向，用户无法提前判断将要切换到哪一集。

本次修订目标：

- 从单集领域模型中彻底删除简介。
- 在剧集详情页提高选集区域的信息密度，并保留每集时长。
- 在剧集播放页让上一集和下一集导航明确显示目标单集名称。

电影简介和剧集简介不受影响。

## 2. 已确认方案

### 2.1 删除单集简介

采用完整纵向删除方案，不保留兼容字段：

- 管理后台新增和编辑单集时不再显示或提交单集简介。
- 共享前端 API 类型不再声明单集简介。
- 后端单集请求 DTO、响应 DTO、服务和数据访问层不再读取或写入单集简介。
- 公开剧集详情响应中的单集对象不再返回简介。
- 数据库通过新增迁移删除 `episode.synopsis` 列；回滚迁移恢复该列为非空文本并使用空字符串作为默认值。

迁移升级会永久删除已有的单集简介数据。用户已确认接受这一行为。

### 2.2 剧集详情页选集布局

采用已确认的 B 方案：固定双列选集卡片。

- 桌面端选集区域使用两列等宽网格，一行展示两集。
- 每张卡片左侧显示集序号和名称，格式为“第 N 集 · 名称”。
- 每张卡片右侧显示时长，复用现有时长格式：有值时显示向上取整后的分钟数，例如“42 分钟”；缺失时显示“时长未知”。
- 集名区域允许收缩；空间不足时使用省略号，时长保持完整并固定靠右。
- 有可播放视频的单集整张卡片作为播放入口。
- 没有可播放视频的单集保留“暂无可播放视频”含义，并使用不可点击的弱化状态。
- 窄屏下网格切换为单列，保证名称和时长可读。
- 季切换、季排序和单集排序规则保持不变。

### 2.3 播放页相邻单集导航

- 当相邻单集存在时，按钮显示方向、集序号和名称，例如“上一集：第 1 集 · 启程”和“下一集：第 3 集 · 灯塔”。
- 导航仍按现有的可播放单集有序列表计算，因此不会跳转到没有公开视频的单集。
- 位于第一集时，上一集按钮保持禁用并显示“上一集”；位于最后一集时，下一集按钮保持禁用并显示“下一集”。
- 点击行为、最近观看单集记录和浏览器历史导航规则保持不变。
- 在窄屏或名称较长时允许按钮文字换行，不能通过仅显示省略号隐藏目标集名称。

## 3. 数据与接口变更

单集继续包含以下公开和管理字段：

- 标识
- 所属季标识
- 集序号
- 名称
- 时长
- 视频信息或公开视频地址
- 生命周期状态及版本、时间戳等管理元数据

单集不再包含 `synopsis`。电影和剧集顶层对象仍包含 `synopsis`，目录搜索继续匹配电影和剧集的名称及简介，不搜索单集。

本次变更直接更新现有接口契约，不引入并行版本或废弃期。前端和后端必须在同一版本中部署。

## 4. 错误与边界处理

- 时长为空不是错误，详情页显示“时长未知”。
- 某季没有公开单集时，继续显示现有空状态。
- 只有一个可播放单集时，上一集和下一集按钮均禁用。
- 单集名称为空的约束不变，仍由现有后端校验拒绝。
- 数据库迁移失败时部署必须停止，不能在旧数据库结构上启动依赖新契约的应用。

## 5. 测试策略

遵循测试驱动开发：先修改或新增测试并确认失败原因，再编写最少实现代码。

### 5.1 后端与数据库

- 迁移测试验证升级后 `episode.synopsis` 列不存在，回滚后该列恢复。
- 单集创建和更新接口测试验证请求不再需要或输出简介。
- 公开剧集详情接口测试验证单集响应不包含简介，其他字段和排序保持不变。
- 编译期和序列化测试覆盖共享契约调整导致的所有调用点。

### 5.2 管理后台

- 单集编辑测试验证页面不存在“单集简介”输入框。
- 保存测试验证请求体只包含集序号、名称和时长等有效字段。

### 5.3 公开站

- 详情页测试验证每集显示名称和格式化时长，且不存在单集简介。
- 布局通过样式断言或端到端视口测试验证桌面双列、窄屏单列。
- 播放页测试验证可用的上一集和下一集按钮包含目标集序号与名称。
- 边界测试验证首集、末集和唯一单集时按钮的禁用状态与文案。

## 6. 非目标

- 不调整电影或剧集顶层简介。
- 不修改时长的录入单位或格式化算法。
- 不改变单集发布状态、排序或可见性规则。
- 不重新设计播放页右侧的当前季选集器。
- 不为旧版前端保留单集简介接口兼容层。
