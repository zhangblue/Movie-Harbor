# MCP 单集整数分钟设计

日期：2026-10-27

## 用户要求与范围

单集时长与电影统一按分钟四舍五入取整。本增量覆盖同日元数据规格中“单集写入保留精确秒数”的规则。仅调整 MCP 写入逻辑，不更改后端、数据库、播放器或已有记录。

## 规则

- 创建和修改单集继续接收原有正整数 `duration_seconds`，维持接口兼容。
- 通过已有分钟换算函数计算 `max(1, round(seconds / 60))`，再乘以 60 向后端保存。
- `89` 秒保存为 `60` 秒；`90` 秒保存为 `120` 秒；`3584` 秒保存为 `3600` 秒。
- 原有最大秒数校验保持生效；最大合法输入取整后仍在后端范围内。
- 元数据更新未提供时长时，不提交时长字段，不改写旧时长。
- 通用探测与转换仍返回秒数；只读查询不改写已有记录。
- 入库计划展示单集取整后的整数分钟，可同时列出原探测秒数。
- 生命周期、确认、版本并发校验和媒体上传保持现有规则。

## 验证

创建和更新工具测试覆盖向上、向下、半分钟、最少一分钟、整分钟和最大值；非法输入在 HTTP 前拒绝。协议说明包含取整规则。隔离 E2E 直接读取后端记录，确认创建与更新结果保存为整分钟秒数。运行 MCP 全量测试、构建、文档契约、隔离 E2E 和 diff 检查后提交 main 并推送 GitHub。
