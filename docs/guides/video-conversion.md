# 视频转换指南

[返回项目 README](../../README.md)

此工具在上传前处理本机单个 MKV 或 MP4，生成网站兼容的 MP4。它是源码仓库中的独立命令行工具，不访问网站 API、数据库或媒体库；网站服务端仍不自动转码，也不会因本工具增加 FFmpeg 运行时依赖。

## 准备环境

在运行工具的电脑上准备项目开发环境（见[开发指南](development.md)），并安装包含 FFmpeg 和 FFprobe 的发行包。两者必须同时能从当前终端的 `PATH` 执行；可参考 [FFmpeg 官方下载入口](https://ffmpeg.org/download.html)。

先在同一终端自检：

```bash
ffmpeg -version
ffprobe -version
```

两条命令都应输出版本信息。工具会检查本次转换所需的编码器；若缺少 `libx264`、`aac` 或 `mov_text`，请换用包含所需编码器的 FFmpeg 发行包。仅复制的轨道不要求对应编码器。

## 转换一个文件

在项目根目录运行：

```bash
npm run convert:video -- --help
npm run convert:video -- "/videos/示例电影.mkv"
npm run convert:video -- "/videos/示例电影.mp4"
```

每次只接受一个本机普通文件；扩展名限 `.mkv` 或 `.mp4`，大小写均可。不支持目录、批量输入或远程 URL，也没有自定义输出路径或强制覆盖选项。文件名含空格或特殊字符时，请像示例一样使用终端支持的引号。

输出固定在输入目录，名称为 `<输入基本名>.movie-harbor.mp4`：

| 输入 | 输出 |
| --- | --- |
| `/videos/示例电影.mkv` | `/videos/示例电影.movie-harbor.mp4` |
| `/videos/示例电影.mp4` | `/videos/示例电影.movie-harbor.mp4` |

如果输出路径已存在，工具在探测和转换前报错，不覆盖文件；即使运行途中出现同名目标，最终发布也会拒绝覆盖。示例中的两个输入会产生同名输出，因此应分别运行，或先自行移动已有输出。

处理期间显示中文进度；能获取可靠时长时显示百分比，否则显示已处理时间。成功时输出 `完成：<输出路径>`。退出码 `0` 表示成功或帮助，`2` 表示参数错误，`1` 表示依赖、探测、转换或文件处理失败。

## 轨道与编码规则

- 视频：选择第一条非封面视频轨，仅输出这一条主视频。H.264 且像素格式为 `yuv420p` 时直接复制；其他情况转为 H.264（`libx264`），固定 CRF 20、`medium` 和 `yuv420p`。转码保持原分辨率，奇数宽或高缩小 1 像素。
- 音频：按原顺序保留所有音轨。AAC 直接复制，其他编码逐轨转换为 AAC，每轨目标码率 192 kbps；不主动下混声道。
- 字幕：按原顺序保留所有文本字幕并转换为 MP4 的 `mov_text`。转换不保证保留 ASS 等字幕的字体、样式与排版，也不保证所有浏览器都提供内嵌字幕或音轨切换。
- 容器：始终生成新 MP4，并启用 `faststart`，将播放所需元数据移至文件前部。兼容轨道的复制仍会重新封装，不会直接复用原文件。

保留全局元数据、章节以及映射轨道的语言、标题和 disposition；不输出封面视频、其余视频轨、附件或数据轨。没有音轨或字幕的文件也可转换。

图像字幕无法转换为文本字幕。检测到 PGS（`hdmv_pgs_subtitle`）、VobSub/DVD（`dvd_subtitle`）、DVB（`dvb_subtitle`）或 XSUB（`xsub`）时，工具在 FFmpeg 转换开始前停止，报错列出轨道索引和编码名称。它不会静默丢弃这些字幕，也不会 OCR 或烧录字幕。未知字幕编码会尝试文本转换；若 FFmpeg 不支持，整次转换失败并显示诊断摘要。

## 文件安全与上传复核

工具不修改原片。转换先写入同目录的唯一临时 `.mp4` 文件，成功后才将完整文件原子发布到固定输出路径，并移除临时文件名。目录需可写且支持硬链接；不支持时会报错，不能改用覆盖操作。

转换前至少预留一个完整输出文件的空间，输出可能比原片更大。正常失败或通过 `Ctrl+C` / `SIGTERM` 中断时，工具会清理本次临时文件；若清理失败，会明确报告路径。强制终止进程或断电可能留下临时文件，确认没有转换进程运行后可按报错或临时文件路径手动处理。若最终文件已发布但临时名字删除失败，最终文件仍完整，按提示删除临时名字即可。

成功后先在本机抽查画面、声音、音轨和字幕，再上传生成的 `.movie-harbor.mp4`。工具只按约定生成兼容格式；网站上传校验仍是最终判断。上传格式与容量限制见[部署指南](deployment.md)。
