## 管理媒体路径与内容导出

电影详情和剧集的单集视频区域显示已上传视频的只读“本地存储路径”，例如 `/media/video/ab/<uuid>.mp4`。这是容器内完整路径，不是 `MEDIA_HOST_DIR` 对应的宿主机绝对路径；未上传的视频不会显示路径，路径也不能用于修改媒体。

在管理后台“内容管理”标题旁点击“导出 JSON”，可下载 `movie-harbor-content-export-YYYYMMDD-HHmmss.json`，文件名时间使用服务端 UTC。导出包含全部草稿、已发布和已归档电影与剧集，不受当前筛选、搜索或分页影响；JSON 中不包含状态、数据库 ID 或媒体 ID。

电影和剧集都导出年份及题材名称数组：缺少年份显式为 `null`，无题材为 `[]`；单集不重复这些字段。电影还导出名称、简介、海报路径、视频路径和秒数；剧集还导出名称、简介、海报路径及扁平单集数组，每集包含季编号、集编号、名称、视频路径和秒数。海报路径和视频路径均为容器内路径；缺失的媒体或时长显式为 `null`。导出是只读元数据快照，不包含媒体文件，不能代替数据库与媒体目录的一致备份。

### 从 JSON 导入内容

在安装 Node.js 的源码目录执行以下命令；目标站点须已部署并创建管理员：

```bash
npm run import:content -- \
  --json /backup/movie-harbor-content-export.json \
  --media-root /backup/media \
  --target https://movies.example.com \
  --admin-name admin
```

命令会交互读取管理员密码，输入时不回显；自动化时从标准输入的第一行读取密码。密码不接受命令行参数，也不写入进度文件。`--target` 只能是站点的 HTTP(S) origin，不能带凭据、路径、查询或片段；HTTPS 使用证书验证，不提供禁用 TLS 验证的选项。

`--media-root` 对应旧实例容器内的 `/media` 根目录。例如 JSON 中的 `/media/video/ab/<uuid>.mp4` 会从 `/backup/media/video/ab/<uuid>.mp4` 读取。完整预检成功后才登录并导入；路径必须属于受控媒体目录，符号链接不能逃出根目录。海报支持 JPG、PNG、WebP，视频仅支持 MP4、WebM，仍须通过目标站点的格式、编码与大小校验。

导入会按题材名称复用已启用题材，并创建缺失题材；同名题材已停用时停止。电影、剧集和单集均创建为草稿，保留名称、简介、年份、题材、季集编号及秒数；空媒体保持为空。目标中同类型、同名称的已有内容会打印 `SKIP` 并跳过，不覆盖；电影和剧集分别判断同名。

进度默认保存在 JSON 旁的 `<JSON 路径>.movie-harbor-import-progress.json`，以 `0600` 权限原子保存目标 ID、版本及成功步骤，不保存密码、Cookie 或 CSRF token。中断后使用同一 JSON、目标站点和同一命令恢复；保留进度文件，已保存的步骤不会重复执行。来源内容或目标站点不匹配会拒绝继续，目标已删除、被编辑或不再为草稿时会报告失败。不要并行执行使用同一进度文件的导入。

远端 API 成功与本地进度落盘之间存在跨服务窗口：如果此时断电、断网或保存失败，目标可能已创建草稿或更新版本，但进度尚未记录。重跑可能出现同名 `SKIP` 或版本冲突；请先在管理后台人工检查同名草稿、媒体和版本，再决定后续处理。工具不会按名称接管对象，也不会覆盖目标修改。

结尾汇总完成、恢复、跳过及失败数。仅有同名跳过仍退出 `0`；内容失败或致命错误退出非零，排除原因后可重新运行。导入不会还原原数据库 ID、发布状态、账号或系统配置，不等于备份恢复；完整恢复仍需数据库与媒体目录的一致备份集。

完整备份与恢复见[媒体与备份指南](media-and-backup.md)；目标站点访问配置和上传限制见[部署指南](deployment.md)。
