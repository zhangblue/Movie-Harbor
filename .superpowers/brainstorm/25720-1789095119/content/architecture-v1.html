总体架构：两套前端 + 统一 API

首版保持单机 Docker Compose 部署，但公开体验、后台管理与服务端职责彼此独立。

浏览器端
PUBLIC WEB

公开媒体站

无需登录：浏览、分类筛选、搜索、详情、播放、浏览器本地观看进度。

ADMIN WEB

管理后台

单一管理员登录：内容录入、季集维护、文件上传、发布、归档与永久删除。

↕ 统一 HTTP API ↕
服务端
BACKEND API

统一业务服务

公开查询 API 与管理员 API 分区；内部包含认证、内容目录、发布流程、分类预置、文件登记和校验。

DATABASE

关系型数据库

电影、剧集、季、集、题材、状态及媒体元数据。

MEDIA VOLUME

本地媒体卷

海报和可直接播放的视频；发布后使用公开 URL，由反向代理高效传输。

部署单元

Docker Compose 编排公开站、管理后台、API、数据库四个服务，并挂载一个持久媒体目录。反向代理作为推荐的生产入口，但不强制内置。
